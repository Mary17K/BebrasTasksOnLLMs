This project was done in the scope of an internship at the department for Cognitive Modeling in Tübingen. 
41 tasks from the International Challenge for Computational Thinking from 2023 were translated into textual tasks in order to be used for testing 
LLM capabilities. 
Three LLMs (GPT-4o, Gemini 2.5 flash and GPT5) gave an overall of 174 responses.
All tasks and notebooks and well as collected data is publically available and does not claim to be without flaws.
